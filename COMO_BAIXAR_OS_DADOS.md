# Como Obter o Dataset Original

Em conformidade com as orientações do Edital nº 1/2026 da SYNAPTA (que determinam a não republicação direta do dataset original caso restrito pelas condições de uso da plataforma), siga os passos abaixo para baixar a base oficial:

1. Acesse a página oficial do dataset no Kaggle:
   - **Link:** [Sao Paulo Housing Prices - Kaggle](https://www.kaggle.com/datasets/renatosn/sao-paulo-housing-prices)
2. Clique no botão **Download** (no canto superior direito da página) para baixar o arquivo compactado `archive.zip`.
3. Extraia o arquivo `data.csv` e posicione-o na raiz do projeto (ou dentro desta pasta `data/`, ajustando o caminho caso necessário).
4. Execute o script `analise_alugueis_sp.py` ou abra o notebook `analise_alugueis_sp.ipynb` no Jupyter / Google Colab.
