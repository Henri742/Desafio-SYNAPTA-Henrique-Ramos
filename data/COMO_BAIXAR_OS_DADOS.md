# Como baixar o dataset

O arquivo original não foi colocado no repositório para respeitar as condições de uso do Kaggle.

1. Entre em https://www.kaggle.com/datasets/renatosn/sao-paulo-housing-prices (precisa estar logado no Kaggle).
2. Clique em **Download** e extraia o `.zip`.
3. Copie o arquivo `data.csv` para esta pasta (`data/data.csv`).

Se preferir deixar o `data.csv` na raiz do projeto, o código também encontra ele lá.

O arquivo deve ter 11.657 linhas e estas colunas:
`address, district, area, bedrooms, garage, type, rent, total`
